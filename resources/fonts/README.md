# 字体文件说明

本插件在渲染图片时使用了三款中文字体。**由于版权限制，字体文件不随仓库分发**，需要你自行获取后放入本目录。

## 需要的文件

| 文件名（必须一致） | 字体名 | 用途 | 大小 |
|---|---|---|---|
| `红豆大黑体.ttf` | 红豆大黑体 | 玩家昵称、物品名、段位场标题 | ≈ 20 MB |
| `文鼎特毛楷简繁.ttf` | 文鼎特毛楷简繁 | 累计寻觅次数、含保底、四麻战绩等标题 | ≈ 17 MB |
| `汉仪文黑75W.ttf` | 汉仪文黑 75W | 所有数字（点数、PT、时间、UID 等） | ≈ 3 MB |

## 放置位置

```
plugins/Majsoul-Plugin/resources/fonts/
├── README.md          ← 本文件（已在仓库中）
├── 红豆大黑体.ttf      ← 需要你放入
├── 文鼎特毛楷简繁.ttf   ← 需要你放入
└── 汉仪文黑75W.ttf     ← 需要你放入
```

**文件名必须完全一致**（含中文名与 `.ttf` 扩展名），插件按文件名查找。

## 缺字体时会怎样

插件不会报错崩溃，会自动回退到系统中文字体（微软雅黑 / 楷体）：

- 有字体：卡片效果与官方风格一致
- 缺字体：文字仍正常显示，只是字形变成系统默认字体

启动时控制台会输出类似警告，提示缺少哪个字体文件：

```
[fonts] 缺少字体文件 红豆大黑体.ttf，回退系统字体
```

## 如何获取

这三款均为商业字体，请通过正规渠道购买授权，例如：

- **红豆大黑体** — 爱给网等字体平台
- **文鼎特毛楷简繁** — 文鼎字库官网 / 授权代理商
- **汉仪文黑75W** — 汉仪字库官网 / 授权代理商

## 为什么不做内置

把字体以 Base64 编码嵌入代码、或转成 woff2 格式，体积会更大（Base64 约膨胀 33%），
且**版权性质完全不变**——依然是在分发字体文件的副本。因此本项目选择让用户自备。

如果你希望开箱即用且无版权顾虑，可以改用 OFL 开源协议的近似风格字体，
再修改 `components/fonts.js` 里的 `FONT_DEFS` 文件名即可（例如思源黑体、霞鹜文楷、得意黑）。
