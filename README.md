<a id="前言插件简介"></a>

## **丨前言&插件简介**
一个雀魂麻将多功能插件，插件不包括TRSS-Yunzai，应该配合[**TRSS-Yunzai**](https://github.com/TimeRainStarSky/Yunzai)使用：

项目地址：https://github.com/Xcheng-dada/Majsoul-Plugin

> [!TIP]
> 本插件在功能方向上受 [Majsoul_bot](https://github.com/DaiShengSheng/Majsoul_bot/) 和 [MajsoulUID](https://github.com/KimigaiiWuyi/MajsoulUID) 启发，核心逻辑由本团队使用 JavaScript 独立实现，并针对 TRSS-Yunzai 框架进行了适配。

> [!IMPORTANT]
> **与上游项目差异**
> - 修复段位分显示负数、三麻走势图（修正为 3 条线）
> - 雀士图鉴保持与官方同步更新，移除无效抽卡礼物
> 
> **体验优化亮点**
> - 查询图表支持房间筛选，柱状图百分比显示
> - 对局记录与订阅推送纯文字 → Canvas 重绘图片
> - 搜索配图、帮助图重做，立绘随机展示
> - 图表圆点与线条精确对齐，视觉效果更整洁

<a id="安装方法"></a>

## 丨安装方法
1.  在 TRSS-Yunzai 根目录下使用以下命令拉取本项目（建议加 `--depth 1` 仅克隆最新提交，减少下载体积）
    ```
    git clone --depth 1 https://github.com/Xcheng-dada/Majsoul-Plugin.git ./plugins/Majsoul-Plugin
    ```
2.  安装依赖（请确保当前位于 TRSS-Yunzai 根目录，`pnpm install` 会自动识别并安装本插件的依赖）
    ```
    pnpm install
    ```
3.  获取本地 API 程序（牌谱分析功能必需，否则无法使用 `#牌谱Review` / `#雀魂场况`）。该程序随本仓库 **Release** 一同发布，**不在插件源码目录内**。请前往本仓库的 Release 页面下载并解压，将对应平台的程序文件放置到插件目录下的 `api/` 文件夹（详细步骤见下方「[本地 API 程序从哪里获取？](#本地-api-程序从哪里获取)」）。
4.  重启 TRSS-Yunzai，进入机器人在的群聊，即可正常使用本插件。

<a id="已实现的功能"></a>

## 丨已实现的功能

### 丨雀魂抽卡模块
*   **每日签到**：签到领取随机 **150~250** 辉玉和 **1** 张寻觅卷轴，有小概率**暴击**（辉玉翻倍）；连续签到 **7 天**额外获得 1 张十连寻觅卷轴；首次签到送**欢迎礼包**（500 辉玉 + 1 寻觅卷轴）。
*   **寻觅（抽卡）**：单抽消耗 **1 张寻觅卷轴或 200 辉玉**，十连消耗 **1 张十连寻觅卷轴或 1800 辉玉**（单张寻觅卷轴不可十连）。每次寻觅获得 **1 点信仰**（十连 +10）。
*   **货币与自动兑换**：抽到重复物品自动转化为货币——礼物转**星之粉尘**（中级 5 / 高级 25）、重复装扮转**星之石**（5）、重复雀士转**许愿石**（限定 150 / 普通 75）。许愿石、星之石、粉尘满一定数量后**自动兑换**成寻觅卷轴，无需手动操作。
*   **信仰兑换**：攒够信仰可直接兑换雀士——**150 信仰**兑普通雀士、**300 信仰**兑限定雀士。
*   **收集图鉴**：自动记录抽到的雀士与装扮，`#雀魂图鉴` 生成收集进度图（未收集灰度展示、新获得标注 NEW、支持分类与分页）。
*   **辉玉红包**：机器人主人可发辉玉红包，群友拼手气抢红包（5 分钟过期）。过期后未领完的剩余辉玉进入公共红包池（群内会播报金额），随下一次发红包一起发放。
*   **奖励邮件**：管理员可向全群发放奖励邮件（任意奖励组合），群友一键领取（30 天过期）。
*   **多卡池系统**：支持竹林之路 / 樱花之路、预配置联动池与限时UP/贵人池。主人 `#开启联动 <池名>` 全局开启联动，`#创建UP池` 发放贵人/限时UP；群员可用 `#切换竹林` / `#切换樱花` / `#切换卡池 <池名>` 切换**仅对自己生效**的个人卡池，`#我的卡池` 可查看当前卡池与可用池列表。

### 丨雀魂用户管理模块
*   **玩家搜索**：搜索玩家信息（昵称、UID、段位），支持多节点自动切换，也支持好友码搜索。
*   **UID绑定**：将雀魂玩家UID与QQ号绑定，便于后续查询。
*   **多账号管理**：支持绑定多个雀魂UID，并可设置主账号。
*   **绑定切换**：可随时切换已绑定的主账号。
*   **账号解绑**：支持解绑指定UID或全部解绑。

### 丨雀魂对局订阅模块
*   **对局订阅**：订阅指定玩家的四麻/三麻对局，自动推送到群聊。
*   **定时检查**：四麻每 3 分钟检查一次，三麻每 5 分钟检查一次（默认间隔，如需调整可在插件代码中修改 `index.js` 的 `SCHEDULES` 配置）。
*   **播报内容**：包含对局场次、牌谱链接、玩家信息（含分数和段位分变化）及时间。
*   **灵活管理**：支持查看订阅状态、临时开启/关闭播报、删除订阅。
*   **注意**：订阅依赖牌谱屋（amae-koromo）数据，受其 API 限制，仅 `金之间及以上` 有对局记录的玩家可订阅。

### 丨雀魂对局查询模块
*   **即时查询**：查询玩家最近对局记录，支持四麻和三麻。
*   **详细信息**：包含玩家排名、段位、分数、PT变化、房间类型、时间和牌谱链接。
*   **多模式支持**：支持通过昵称查询（省略昵称时使用已绑定UID），四麻用 `#(雀魂/四麻)对局`、三麻用 `#三麻对局` 分别查询。
*   **段位场筛选**：可在指令后追加段位场关键词，仅统计该场次的对局。支持 `金之间`/`玉之间`/`王座之间`，并支持模糊别名（如 `金`/`金间`、`玉`/`玉间`、`王座`/`王座间`），例如 `#雀魂对局 玩家名 金`。
*   **注意**：受牌谱屋（amae-koromo）API 限制，仅 `金之间及以上` 有对局记录的玩家可查询。

### 丨雀魂玩家数据查询模块
*   **玩家数据查询**：查询玩家详细战绩数据，分为四麻（`#雀魂查询`/`#查询四麻`）与三麻（`#查询三麻`）分别查询。
*   **战绩统计**：包含自摸率、和牌率、首位率、放铳率等详细数据。
*   **对局走势**：展示最近16场对局的分数走势图表（带房间筛选时仅展示该房间对局，走势标题显示房间名）。
*   **段位场筛选**：指令后追加段位场关键词（含上述模糊别名）后，仅展示对应房间的战绩与走势，顶部标题显示「昵称 · 房间名」。某模式无对局记录时该模式显示暂无数据。
*   **友人场数据查询**：`#雀魂查询 友/友人/友人场 <玩家名>` 查看玩家**友人场**战绩（四麻）；三麻用 `#查询三麻 友 <玩家名>`。
*   **比赛场数据查询**：`#雀魂查询 赛/赛事/比赛/比赛场 <玩家名>` 查看玩家**比赛场**战绩（四麻）；三麻用 `#查询三麻 赛 <玩家名>`。
*   **好友码查询**：`#雀魂查询 <好友码>` 通过好友码获取玩家战绩（需本地 API 已登录，自动转换好友码为 UID 后查询）。

### 丨雀魂AI牌谱分析模块
*   **AI牌谱分析**：通过 `#牌谱Review <URL>` 提交牌谱至 Mortal 进行 AI 分析，逐局生成牌谱分析图（含手牌、副露、吃碰杠过程与 AI 点评）。Mortal 引擎仅支持**四麻牌谱**（含四人东、四人半庄），**三麻牌谱暂不支持 AI 分析**（提交时直接提示不支持，详见下方常见问题）。
*   **牌谱场况查看**：通过 `#雀魂场况 <URL> <局> [巡]` 查看指定局/巡的牌谱过程图（局数、巡数均从 1 开始，巡数省略则展示整局），支持 `#场况` / `#牌谱详情` 等价指令。**需先对该牌谱执行过 `#牌谱Review` 后方可查看**。
*   **雀魂账号登录（必须）**：牌谱分析依赖本地 API 登录态以获取牌谱原始数据及真实昵称/头像，**未登录无法进行牌谱分析**。通过 `#雀魂登录 <账号> <密码>` 登录，登录态由本地 API 持久保存。建议使用小号登录（详见下方常见问题）。

## 丨常见问题 Q&A
### 丨抽卡时提示"插件加载错误"或类似错误？
1.  **确保依赖已安装**：在TRSS-Yunzai根目录内执行 `pnpm install`。
2.  **检查Node.js版本**：确保版本为 **18** 或以上。
3.  **重启Yunzai**：修改配置或安装依赖后，请重启机器人。
4.  **查看详细日志**：错误信息通常会在控制台输出，根据日志排查问题。

### 丨管理员指令没有反应？
请确认发送指令的QQ号已在TRSS-Yunzai的 `config.yaml`（或类似配置）中设置为**管理员 (admin)** 或**主人 (master)**。

### 丨搜索玩家时提示"暂未搜索到该玩家"？
1.  **可使用好友码查询**：若提示暂未搜索到该玩家，可使用好友码查询——`#雀魂查询 <好友码>` 或 `#雀魂搜索 <好友码>`（需本地 API 已配置并登录）。
2.  **检查昵称是否正确**：请确保输入完整的玩家昵称。
3.  **尝试英文名搜索**：部分玩家可能使用英文名或特殊字符。

### 丨绑定UID时提示"UID格式不正确"？
- 雀魂UID为5-10位数字，请检查输入是否正确。
- 确保输入的是纯数字UID，不包含其他字符。

### 丨切换UID时提示"尚未绑定该UID"？
请先使用`#雀魂我的绑定`查看已绑定的UID列表，然后使用列表中的UID进行切换。

### 丨为什么抽不到某些限定装扮？
限定装扮大部分通过活动获取或限时复刻，由于复刻时间不确定且获取方式多样，目前插件未收录所有限定装扮。

### 丨魂天段位图标为什么没有等级区分？
- 目前魂天 1~20 级统一使用魂天图标（暂无分级素材）。
- 如您有官方分级图标资源，欢迎提交 PR 补充。
- 雀魂官方目前只开放魂天最高 20 级，所以 20 级只显示当前魂珠数量，达到 20 魂珠后不再升级。

### 丨玩家数据查询图片中的雀士服饰是怎么决定的？
查询图片会依照玩家**当前使用的服饰**输出对应立绘；仅当该服饰未被收录时，才会从 `person_full` 文件夹随机选择立绘代替。

### 丨使用牌谱分析功能时提示"当前未登录"？
- **原因**：未登录是因为本地 API 没有登录态，无法获取牌谱原始数据，因此无法进行分析。
- **解决**：请先执行 `#雀魂登录 <账号> <密码>` 完成登录。
- **说明**：登录态由本地 API 持久保存，登录一次后无需重复登录。
- ⚠️ **账号安全提示**：登录由本地 API（Majsoul.ProtocolLogin.Api 对应平台程序）保存账号密码并持有登录态，操作真实账号，**建议使用小号登录，切勿使用重要主账号**，本插件不保证账号的绝对安全。

### 丨本地 API 程序从哪里获取？
- 本地 API 程序（Windows 为 `Majsoul.ProtocolLogin.Api-win-x64.exe`，Linux 为 `Majsoul.ProtocolLogin.Api-linux-x64`）随本仓库的 **Release** 一同发布，**不在插件源码目录内**。
- 若要使用牌谱分析功能，请前往本仓库的 Release 页面，下载对应平台（Windows / Linux）的压缩包并解压，将解压得到的程序文件放置到插件目录下的 `api/` 文件夹：
  ```
  Majsoul-Plugin/api/Majsoul.ProtocolLogin.Api-win-x64.exe   # Windows
  Majsoul-Plugin/api/Majsoul.ProtocolLogin.Api-linux-x64    # Linux
  ```
- 放置完成后启动 Yunzai，插件会根据配置自动拉起该程序（监听 `127.0.0.1:5088`，Windows 与 Linux 均支持自动拉起），拉起后直接用 `#雀魂登录 <账号> <密码>` 完成登录即可。
- 该程序自带以下本地页面，可供查看与调试：
  - **WebUI**：`http://127.0.0.1:5088`
- ⚠️ 该程序与 `5088` 端口**一一绑定**，同一时间只能有一个实例运行。若手动再开一个会因端口被占用而闪退。请勿重复启动。

### 丨AI牌谱分析支持哪些规则/模式？
- **当前引擎（Mortal）**：支持**四麻牌谱**，含**四人东**与**四人南**，且需为**一般规则（标准规则）**牌谱。
- **三麻暂不支持**：当前 Mortal 引擎不支持三人麻将，**三麻牌谱目前无法使用 AI 分析功能**。

### 丨为什么玩家搜索 / 对局订阅 / 对局查询提示需要 token？
- 雀魂牌谱屋（amae-koromo）的 API 现在需要 **Bearer token** 才能访问数据，未配置 token 时以下功能将不可用：
  - **玩家搜索**（`#雀魂搜索`）
  - **对局订阅**（`#雀魂订阅` 等播报）
  - **对局查询**（`#雀魂对局` / `#三麻对局`）
  - **玩家数据查询**（`#雀魂查询` / `#查询三麻`）
- **如何获取 token**：需自行联系牌谱屋（amae-koromo）作者获取专属 Bearer token。
- **如何配置**：获取到 token 后，**【私聊机器人】** 发送（仅私聊支持，且需为机器人主人）：
  ```
  设置token <你的token>
  ```
  配置成功后立即生效并保存至 `data/token.json`，无需手动编辑文件；也可直接写入 `data/token.json` 的 `{"token":"你的token"}`。
