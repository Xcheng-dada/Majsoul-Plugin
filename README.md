<a id="前言插件简介"></a>
## **丨前言&插件简介**
一个雀魂麻将多功能插件，插件不包括TRSS-Yunzai，应该配合[**TRSS-Yunzai**](https://github.com/TimeRainStarSky/Yunzai)使用：

项目地址：https://github.com/Xcheng-dada/Majsoul-Plugin

> [!TIP]
> 本插件部分功能基于 [Majsoul_bot](https://github.com/DaiShengSheng/Majsoul_bot/) 和 [MajsoulUID](https://github.com/KimigaiiWuyi/MajsoulUID) 移植至TRSS-Yunzai。

<a id="安装方法"></a>
## 丨安装方法
1.  在TRSS-Yunzai目录下使用以下命令拉取本项目
    ```
    git clone https://github.com/Xcheng-dada/Majsoul-Plugin.git ./plugins/Majsoul-Plugin
    ```
2.  然后使用如下命令安装依赖
    ```
    cd ./plugins/Majsoul-Plugin
    pnpm install
    ```
3.  重启 TRSS-Yunzai，进入机器人在的群聊，即可正常使用本插件。

<a id="已实现的功能"></a>
## 丨已实现的功能
### 丨雀魂抽卡模块 (功能完整)
*   **十连抽卡**：模拟雀魂抽卡，自动合成并发送十连结果图片。
*   **多卡池系统**：支持多个UP卡池（包括经典卡池与新增卡池），可随时切换。
*   **每日限制**：每个用户每日默认可进行 **5** 次十连抽卡。
*   **群组独立配置**：每个QQ群可以独立设置和切换卡池，互不影响。
*   **管理工具**：机器人主人可为特定用户**设定**抽卡机会、**重置**抽卡次数，群成员可**查询**抽卡状态。

### 丨雀魂用户管理模块 (功能完整)
*   **玩家搜索**：通过雀魂牌谱屋API搜索玩家信息（昵称、ID、段位），支持多节点自动切换。
*   **UID绑定**：将雀魂玩家UID与QQ号绑定，便于后续查询。
*   **多账号管理**：支持绑定多个雀魂UID，并可设置主账号。
*   **绑定切换**：可随时切换已绑定的主账号。
*   **账号解绑**：支持解绑指定UID或全部解绑。

### 丨雀魂对局订阅模块 (功能完整)
*   **对局订阅**：订阅指定玩家的四麻/三麻对局，自动推送到群聊。
*   **定时检查**：四麻每3分钟检查一次，三麻每5分钟检查一次。
*   **播报内容**：包含对局场次、牌谱链接、玩家信息（含分数和段位分变化）及时间。
*   **灵活管理**：支持查看订阅状态、临时开启/关闭播报、删除订阅。

### 丨雀魂对局查询模块 (功能完整)
*   **即时查询**：查询玩家最近对局记录，支持四麻和三麻。
*   **详细信息**：包含玩家排名、段位、分数、PT变化、房间类型、时间和牌谱链接。
*   **多模式支持**：支持通过昵称或UID查询，自动识别四麻/三麻模式。

### 丨雀魂玩家数据查询模块 (功能完整)
*   **玩家数据查询**：查询玩家详细战绩数据，包含四麻和三麻段位信息。
*   **战绩统计**：包含自摸率、和牌率、立直率、打点效率等详细数据。
*   **对局走势**：展示最近16场对局的分数走势图表。

<a id="段位系统说明"></a>
## 丨段位系统说明
插件使用完整的雀魂段位系统，支持以下段位计算：

### 段位等级
1.  **初心**  - 分为1星、2星、3星
2.  **雀士**  - 分为1星、2星、3星
3.  **雀杰**  - 分为1星、2星、3星
4.  **雀豪**  - 分为1星、2星、3星
5.  **雀圣**  - 分为1星、2星、3星
6.  **魂天**  - 分为1~20级，以魂珠计分

### 魂天段位规则
- **计分方式**：魂天使用魂珠计分，每级初始10魂珠，升级需要达到20魂珠
- **分数显示**：魂天1~19级显示 `当前魂珠/20.0`，魂天20级无上限只显示当前魂珠
- **魂花星级**：根据当前魂珠数量显示魂花
  - 0~4.9：0魂花
  - 5~9.9：1魂花
  - 10~14.9：2魂花
  - 15及以上：3魂花
- **降级规则**：魂珠低于0会降级，魂天1级魂珠低于0将降回雀圣3星（4500分）
- **分数变化**：四麻东场0.3/0.1/-0.1/-0.3，南场0.5/0.2/-0.2/-0.5；三麻东场0.3/0/-0.3，南场0.5/0/-0.5；同桌均为魂天段位时魂珠变化翻倍

### 段位分数
- 每个段位有对应的分数上限
- 达到段位上限后自动升段

<a id="常见问题-qa"></a>
## 丨常见问题 Q&A
### 丨抽卡时提示"插件加载错误"或类似错误？
1.  **确保依赖已安装**：在插件目录 (`plugins/Majsoul-Plugin/`) 内执行 `pnpm install`。
2.  **检查Node.js版本**：确保版本为 **18** 或以上。
3.  **重启Yunzai**：修改配置或安装依赖后，请重启机器人。
4.  **查看详细日志**：错误信息通常会在控制台输出，根据日志排查问题。

### 丨管理员指令没有反应？
请确认发送指令的QQ号已在TRSS-Yunzai的 `config.yaml`（或类似配置）中设置为**管理员 (admin)** 或**主人 (master)**。

### 丨搜索玩家时提示"暂未搜索到该玩家"？
1.  **玩家需有金之间对局**：雀魂牌谱屋API仅收录在金之间有对局记录的玩家。
2.  **检查昵称是否正确**：请确保输入完整的玩家昵称。
3.  **尝试英文名搜索**：部分玩家可能使用英文名或特殊字符。

### 丨绑定UID时提示"UID格式不正确"？
- 雀魂UID为5-10位数字，请检查输入是否正确。
- 确保输入的是纯数字UID，不包含其他字符。

### 丨切换UID时提示"尚未绑定该UID"？
请先使用`#雀魂我的绑定`查看已绑定的UID列表，然后使用列表中的UID进行切换。

### 丨为什么抽不到某些限定装扮？
限定装扮大部分通过活动获取或限时复刻，由于复刻时间不确定且获取方式多样，目前插件未收录所有限定装扮。

### 丨魂天段位图标为什么没有等级区分？
- 魂天1~20级的段位图标目前没有对应素材，所有魂天等级统一使用魂天图标
- 如果想提供素材欢迎提交PR
- 雀魂官方目前只开放魂天最高20级，所以20级只显示当前魂珠数量，达到20魂珠后不再升级

### 丨玩家信息查询返回的雀士立绘为什么都是初始装扮？
雀魂角色服饰种类繁多，全量收录工作量巨大。目前仅使用初始装扮立绘。如果想要实现全服饰随机，欢迎提供全服饰资源，或将全服饰资源放入 `person_full` 文件夹后提交PR。
