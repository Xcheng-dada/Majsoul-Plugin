<a id="前言插件简介"></a>

## **丨前言&插件简介**
一个雀魂麻将多功能插件，本插件需配合 [**TRSS-Yunzai**](https://github.com/TimeRainStarSky/Yunzai) 使用：

项目地址：https://github.com/Xcheng-dada/Majsoul-Plugin

> [!TIP]
> 本插件在功能方向上受 [Majsoul_bot](https://github.com/DaiShengSheng/Majsoul_bot/) 和 [MajsoulUID](https://github.com/KimigaiiWuyi/MajsoulUID) 启发，核心逻辑由本团队使用 JavaScript 独立实现，并针对 TRSS-Yunzai 框架进行了适配。

<a id="安装方法"></a>

## 丨安装方法
1.  在TRSS-Yunzai目录下使用以下命令拉取本项目
    ```
    git clone https://github.com/Xcheng-dada/Majsoul-Plugin.git ./plugins/Majsoul-Plugin
    ```
2.  返回 TRSS-Yunzai 根目录，安装依赖（会自动识别并安装本插件的依赖）
    ```
    cd ../..
    pnpm install
    ```
3.  重启 TRSS-Yunzai，进入机器人在的群聊，即可正常使用本插件。

<a id="已实现的功能"></a>

## 丨已实现的功能

### 丨雀魂抽卡模块
*   **十连抽卡**：模拟雀魂抽卡，自动合成并发送十连结果图片。
*   **多卡池系统**：支持多个UP卡池（包括经典卡池与新增卡池），可随时切换。
*   **每日限制**：每个用户每日默认可进行 **5** 次十连抽卡。
*   **群组独立配置**：每个QQ群可以独立设置和切换卡池，互不影响。
*   **管理工具**：机器人主人可为特定用户**设定**抽卡机会、**重置**抽卡次数，群成员可**查询**抽卡状态。

### 丨雀魂用户管理模块
*   **玩家搜索**：通过雀魂牌谱屋API搜索玩家信息（昵称、ID、段位），支持多节点自动切换。
*   **UID绑定**：将雀魂玩家UID与QQ号绑定，便于后续查询。
*   **多账号管理**：支持绑定多个雀魂UID，并可设置主账号。
*   **绑定切换**：可随时切换已绑定的主账号。
*   **账号解绑**：支持解绑指定UID或全部解绑。

### 丨雀魂对局订阅模块
*   **对局订阅**：订阅指定玩家的四麻/三麻对局，自动推送到群聊。
*   **定时检查**：四麻每3分钟检查一次，三麻每5分钟检查一次。
*   **播报内容**：包含对局场次、牌谱链接、玩家信息（含分数和段位分变化）及时间。
*   **灵活管理**：支持查看订阅状态、临时开启/关闭播报、删除订阅。

### 丨雀魂对局查询模块
*   **即时查询**：查询玩家最近对局记录，支持四麻和三麻。
*   **详细信息**：包含玩家排名、段位、分数、PT变化、房间类型、时间和牌谱链接。
*   **多模式支持**：支持通过昵称查询（省略昵称时使用已绑定UID），四麻用 `#(雀魂/四麻)对局`、三麻用 `#三麻对局` 分别查询。
*   **段位房筛选**：可在指令后追加段位房关键词，仅统计该房间的对局。支持 `金之间`/`玉之间`/`王座之间`，并支持模糊别名（如 `金`/`金间`、`玉`/`玉间`、`王座`/`王座间`），例如 `#雀魂对局 玩家名 金`。
*   **注意**：受牌谱屋（amae-koromo）API 限制，仅 `金之间及以上` 段位有对局记录的玩家可被搜索与查询，因此 `铜之间`/`银之间` 不可查询（牌谱屋不收录铜银段位玩家的对局记录）。

### 丨雀魂玩家数据查询模块
*   **玩家数据查询**：查询玩家详细战绩数据，分为四麻（`#雀魂查询`/`#查询四麻`）与三麻（`#查询三麻`）分别查询。
*   **战绩统计**：包含自摸率、和牌率、立直率、打点效率等详细数据。
*   **对局走势**：展示最近16场对局的分数走势图表（带房间筛选时仅展示该房间对局，走势标题显示房间名）。
*   **段位房筛选**：指令后追加段位房关键词（含上述模糊别名）后，仅展示对应房间的战绩与走势，顶部标题显示「昵称 · 房间名」。某模式无对局记录时自动置零并提示暂无数据，不再做无意义请求。

### 丨雀魂AI牌谱分析模块
*   **AI牌谱分析**：通过 `#牌谱Review <URL>` 提交牌谱至 Mortal 进行 AI 分析，逐局生成牌谱分析图（含手牌、副露、吃碰杠过程与 AI 点评）。Mortal 引擎仅支持**四麻牌谱**（含四人东、四人半庄），**三麻牌谱暂不支持 AI 分析**（提交时直接提示不支持，详见下方常见问题）。
*   **牌谱场况查看**：通过 `#雀魂场况 <URL> <局> [巡]` 查看指定局/巡的牌谱过程图（局数、巡数均从 1 开始，巡数省略则展示整局），支持 `#场况` / `#牌谱详情` 等价指令。**须先对该牌谱使用 `#牌谱Review` 分析落盘后才能查看场况**。
*   **雀魂账号登录（必须）**：牌谱分析依赖本地 API 登录态以获取牌谱原始数据及真实昵称/头像，**未登录无法进行牌谱分析**。通过 `#雀魂登录 <账号> <密码>` 登录，登录态由本地 API 持久保存。建议使用小号登录（详见下方常见问题）。

<a id="常见问题-qa"></a>

## 丨常见问题 Q&A
### 丨抽卡时提示"插件加载错误"或类似错误？
1.  **确保依赖已安装**：在TRSS-Yunzai根目录内执行 `pnpm install`。
2.  **检查Node.js版本**：确保版本为 **18** 或以上。
3.  **重启Yunzai**：修改配置或安装依赖后，请重启机器人。
4.  **查看详细日志**：错误信息通常会在控制台输出，根据日志排查问题。

### 丨管理员指令没有反应？
请确认发送指令的QQ号已在TRSS-Yunzai的 `config.yaml`（或类似配置）中设置为**管理员 (admin)** 或**主人 (master)**。

### 丨搜索玩家时提示"暂未搜索到该玩家"？
1.  **玩家需有金之间对局**：雀魂牌谱屋API仅收录在金之间有对局记录的玩家。
2.  **检查昵称是否正确**：请确保输入完整的玩家昵称。
3.  **尝试英文名搜索**：部分玩家可能使用英文名或特殊字符。

### 丨绑定UID时提示"UID格式不正确"？
- 雀魂UID为5-10位数字，请检查输入是否正确。
- 确保输入的是纯数字UID，不包含其他字符。

### 丨切换UID时提示"尚未绑定该UID"？
请先使用`#雀魂我的绑定`查看已绑定的UID列表，然后使用列表中的UID进行切换。

### 丨为什么抽不到某些限定装扮？
限定装扮大部分通过活动获取或限时复刻，由于复刻时间不确定且获取方式多样，目前插件未收录所有限定装扮。

### 丨魂天段位图标为什么没有等级区分？
- 魂天1~20级的段位图标目前没有对应素材，所有魂天等级统一使用魂天图标
- 如果想提供素材欢迎提交PR
- 雀魂官方目前只开放魂天最高20级，所以20级只显示当前魂珠数量，达到20魂珠后不再升级

### 丨玩家信息查询返回的雀士立绘为什么都是初始装扮？
雀魂角色服饰种类繁多，全量收录工作量巨大。目前仅使用初始装扮立绘。如果想要实现全服饰随机，欢迎提供全服饰资源，或将全服饰资源放入 `person_full` 文件夹后提交PR。

### 丨使用牌谱分析功能时提示"当前未登录"？
- 牌谱分析功能（`牌谱Review` / `雀魂场况`）**必须登录本地 API 后才能使用**，未登录时无法取谱，会提示请先登录。
- 如需使用，请先登录雀魂账号：`#雀魂登录 <账号> <密码>`，登录态由本地 API 持久保存。
- ⚠️ **账号安全提示**：登录由本地 API（Majsoul.ProtocolLogin.Api-windows-amd64.exe）保存账号密码并持有登录态，操作真实账号，**建议使用小号登录，切勿使用重要主账号**，本插件不保证账号的绝对安全。

### 丨本地 API 的 exe 从哪里获取？
- 本地 API 程序（`Majsoul.ProtocolLogin.Api-windows-amd64.exe`）随本仓库的 **Release** 一同发布，**不在插件源码目录内**。
- 若要使用牌谱分析功能，请前往本仓库的 Release 页面，下载并解压其中的 exe 压缩包，将解压得到的 exe 文件放置到插件目录下的 `exe/` 文件夹：
  ```
  Majsoul-Plugin/exe/Majsoul.ProtocolLogin.Api-windows-amd64.exe
  ```
- 放置完成后启动 Yunzai，插件会自动拉起该 exe（监听 `127.0.0.1:5088`），拉起后直接用 `#雀魂登录 <账号> <密码>` 完成登录即可。
- 该 exe 自带以下本地页面，可供查看与调试：
  - **WebUI**：`http://127.0.0.1:5088`
  - **API 文档（Swagger）**：`http://127.0.0.1:5088/swagger`
- ⚠️ 该 exe 与 `5088` 端口**一一绑定**，同一时间只能有一个实例运行。若手动再开一个 exe 会因端口被占用而闪退。请勿重复启动。

### 丨AI牌谱分析支持哪些规则/模式？
- **当前引擎（Mortal）**：支持**四麻牌谱**，含**四人东**与**四人南**，且需为**一般规则（标准规则）**牌谱。
- **三麻暂不支持**：当前 Mortal 引擎不支持三人麻将，**三麻牌谱目前无法使用 AI 分析功能**。

### 丨为什么玩家搜索 / 对局订阅 / 对局查询提示需要 token？
- 雀魂牌谱屋（amae-koromo）的 API 现在需要 **Bearer token** 才能访问数据，未配置 token 时以下功能将不可用：
  - **玩家搜索**（`#雀魂搜索`）
  - **对局订阅**（`#雀魂订阅` 等播报）
  - **对局查询**（`#雀魂对局` / `#三麻对局`）
  - **玩家数据查询**（`#雀魂查询` / `#查询三麻`）
- **如何获取 token**：需自行联系牌谱屋（amae-koromo）作者获取专属 Bearer token。
- **如何配置**：获取到 token 后，**【私聊机器人】** 发送（仅私聊支持，且需为机器人主人）：
  ```
  设置token <你的token>
  ```
  配置成功后立即生效并保存至 `data/token.json`，无需手动编辑文件；也可直接写入 `data/token.json` 的 `{"token":"你的token"}`。
